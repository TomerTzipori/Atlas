# Atlas landing page — redesign

דף נחיתה עצמאי בעברית, RTL, ללא תהליך Build. הקובץ `index.html` מתאים ישירות ל־GitHub Pages.

## פריסה
1. העלו את `index.html` לשורש הריפו `TomerTzipori/Atlas` במקום הקובץ הקיים.
2. ודאו ש־GitHub Pages פעיל ב־Settings → Pages, ומתפרסם מהענף הראשי.
3. בדקו בטלפון ובמחשב, ושלחו ליד ניסיוני (לא פרטים רגישים).

## Botpress
נשמרו שתי שורות הטעינה המקוריות של Botpress (v5.0 + קובץ ההגדרות ב־bpcontent.cloud). נדרש לבדוק שהסוכן עוד פעיל ושדומיין הפריסה מותר בהגדרותיו.

## Make
כתובת ה־webhook שולבה ב־index.html. הטופס שולח JSON בשיטת POST עם Content-Type text/plain כדי לצמצם בעיות preflight ב־GitHub Pages. מצב `no-cors` אומר שהדפדפן אינו יכול לוודא אם Make אכן קיבל ועיבד את המידע. הודעת ממשק מציגה רק שבקשת השליחה הועברה, לא אישור למסירת המייל. לא בוצעה שליחת בדיקה ל־Webhook בזמן הבנייה.

שדות ה־JSON: `name`, `email`, `phone`, `course`, `message`, `consent`, `source`, `submittedAt`, `pageUrl`.

### תרחיש Make
1. צרו תרחיש עם `Webhooks → Custom webhook` והשתמשו ב־webhook שכבר יצרתם.
2. הפעילו `Run once` ושלחו ליד ניסיוני מהאתר הפרוס כדי ש־Make יזהה שדות. אם Make מקבל גוף raw text ולא מפרק JSON, הוסיפו `JSON → Parse JSON` למחרוזת body.
3. הוסיפו `Gmail → Send an email` או מודול SMTP / Email מתאים, בתנאי שהחשבון ממנו נשלח מורשה לכך.
4. שדה `To` צריך להתמפות לכתובת `email` מטופס המשתמש. נושא לדוגמה: `תודה על הפנייה שלך | אטלס`.
5. תוכן HTML: העתיקו את `make-email.html` לגוף ההודעה והחליפו את `{{1.name}}`, `{{1.email}}`, `{{1.phone}}`, `{{1.course}}` בטוקנים האמיתיים שמציע המיפוי של Make — מספרי המודול עשויים להשתנות.
6. מומלץ להוסיף הודעה נפרדת למנהל הפניות עם כל נתוני הליד וכן שמירה במערכת המותרת לכם.
7. הפעילו את התרחיש `ON` ובדקו קבלת דוא״ל בפועל. ודאו שהודעות המייל שלכם עומדות במדיניות הפרטיות והדיוור.

### אבטחה ופרטיות
Webhook שנקרא ישירות מדפדפן באתר סטטי הוא **פומבי**: כל מבקר יכול לראות את הכתובת ולנסות לפנות אליה. אין כאן הגנת שרת מספאם, rate limiting או אימות מקור. לשימוש ייצור עם לידים אמיתיים, עדיף שרת/פונקציית serverless שמחזיקה את ה־webhook בסוד, מאמתת CAPTCHA, ומחזירה תשובת success רק לאחר תגובת Make. אין לאסוף פרטים מסווגים או מידע ביטחוני בטופס.
